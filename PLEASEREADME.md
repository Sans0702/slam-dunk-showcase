
# 🏀 Slam Dunk Showcase

An interactive arcade-style basketball game built using HTML, CSS and JavaScript.

## 🎮 Features

- Four exciting game modes.
- Arcade basketball shooting mechanics.
- Physics-based ball movement.
- Score tracking and high scores.
- Ball skins and court themes.
- Achievements and rewards.
- Sound effects and interactive gameplay.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML Canvas

## 🕹️ How to Play

1. Open the game.
2. Select your preferred game mode.
3. Click or touch the basketball and drag backwards.
4. Release to shoot the ball.
5. Score points and unlock rewards!
